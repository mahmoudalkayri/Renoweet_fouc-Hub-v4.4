# Renoweet Focus Hub v3.8

Adds controlled Deleted management to OS and Bookkeeping.

- OS Deleted view: restore projects or permanently erase them with typed confirmation.
- Restoring an OS project does not recreate cancelled Google Calendar events or resend client notifications automatically.
- Bookkeeping Deleted view: restore invoices/expenses/fuel/auto records.
- Permanent bookkeeping deletion is blocked for records in closed BTW quarters.
- Restores are duplicate-protected and all changes continue through the verified Google Drive save/audit flow.
