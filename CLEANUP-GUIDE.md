# Renoweet Focus Hub cleanup and 2026 layout

## What changed

The live database shown in your screenshot is `Renoweet Data/Active/Renoweet-2026.json`. The manifest is at `Renoweet Data/Renoweet-manifest.json`; existing recovery snapshots are in the shared `Recovery` folder. Your `EXP-…` PDF/JPG files are expense receipts in Q1, Q2 and Q3, shown together by Drive Home even though they are already inside nested folders. **Keep all of these files.**

The updated app can continue reading the legacy `Active` file without moving it. In OS → Database, use **Organize year** after the updated site is deployed and connected. It previews the exact live file and old receipt folders, asks for confirmation, saves and verifies a byte-identical Recovery copy, and moves the same live Drive file ID into `Renoweet Data/2026/Renoweet-2026.json`. It also moves old `Renoweet Data/Proofs/2026/Q1…Q4` proof folders under `Renoweet Data/2026/Proofs/Q1…Q4`. If a quarter already exists in the new layout, it moves the old proof files into that quarter by ID. It does not delete any files or old folders. You can rerun the action after an interruption. Do not manually copy the live JSON.

New receipts immediately upload to `Renoweet Data/YYYY/Proofs/Q#`. New archives and recovery snapshots use `Renoweet Data/YYYY/Archives` and `Renoweet Data/YYYY/Recovery`. The manifest remains at `Renoweet Data/Renoweet-manifest.json` with the same authoritative live file ID. The old shared `Archives` and `Recovery` remain readable; inspect them before any manual move or deletion. BOD reads verified yearly JSON and uses manifest-linked FINAL XLSX only when a year's live JSON is absent. The year folders organize one shared OS/Bookkeeping database per year, so those apps read the same live records.

Project Notebook reads the current-year OS safety cache and sends updates to OS for its verified Drive sync. Focus Hub goals and reminders use the Hub's separate hosted database. Those personal Focus records do not live in the Google Drive year folders.

## Company details

Edit `company-details.txt` in this release, retaining the keys. Save it as plain UTF-8 text and redeploy the Hub files. The quote and invoice previews, payment details, Bookkeeping reports, BOD cover, and app branding read these values. Reopen the page after deployment. The TXT file is included in the site's offline cache. Previously issued PDFs and snapshots are historical documents and will not change when the text file changes.
